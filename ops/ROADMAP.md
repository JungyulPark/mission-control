# ROADMAP — 전략 우선순위

## 큰 그림 (4계층)
1. **생산 엔진**: 콘텐츠 공장(n8n) + 앱 공장(Claude Code 스캐폴딩)
2. **템플릿/복제**: 검증된 1개를 N개로 복제 (이게 성장 레버리지)
3. **오케스트레이션**: 데이터 보고 잘 되는 것 더 찍기 (이 관제탑이 그 시작)
4. **자본/거버넌스**: 결제 필요 시 가족 사업주체/MSO로 분리

## Phase 1 — 수동 공장 (0~6개월) ◀ 현재 여기
목표: 수익이 아니라 **"복제 가능한 템플릿 1개 검증"**.
- [ ] kfortunes 광고형 전환 (결제 제거 + AdSense + 데일리 재방문)
- [ ] AdSense 계정 승인 (도메인 필요, 1~2주 소요 → 먼저 신청)
- [ ] 닥터인사이트 n8n 안정화 → 유튜브 재개
- [ ] 안 되는 레포 정리(접기) — facerank 등 보류, 중복 정리

## Phase 2 — 반자동 복제 (6~18개월)
- 검증 템플릿으로 앱 3~5개 복제 (ksajudaily, Kname, dreamrender...)
- 앱 생산 파이프라인(Claude Code 스캐폴딩) 구축
- 결제 주체(가족/법인) 준비 시작

## Phase 3 — 자동 발행 + 환금 (18개월~)
- 오케스트레이션 자동화
- 누적 트래픽에 결제 붙여 광고+구독 이원화
- 검증된 "공장"을 엑싯 자산으로

## 냉정한 전제
- 병목은 기술이 아니라 **트래픽**. 앱 100개 찍어도 유입 0이면 수익 0.
- Phase 1은 환금이 아니라 **자산 축적** 단계. 단기 큰돈 기대 금지.
- 연구 트랙은 이 로드맵과 별도 시계로 운영(데드라인만 관제탑이 챙김).
